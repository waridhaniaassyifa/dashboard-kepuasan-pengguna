# Dashboard Kepuasan Pengguna

Dashboard sederhana untuk menampilkan dan menganalisis data kepuasan mahasiswa terhadap layanan akademik menggunakan grafik batang, ringkasan statistik, dan tabel penilaian.

Proyek ini dibuat sebagai studi kasus pembelajaran berdasarkan materi “Human-Computer Interaction and Data Visualization” oleh Arafat Febrian Dirza dari Badan Riset dan Inovasi Nasional (BRIN).

## 📌 Latar Belakang

Data penilaian pengguna dapat membantu mengetahui kualitas layanan dan menemukan aspek yang perlu ditingkatkan. Namun, data dalam bentuk angka saja terkadang sulit dipahami.

Oleh karena itu, proyek ini mengembangkan dashboard sederhana untuk menyajikan data kepuasan secara visual sehingga informasi lebih mudah dibaca dan dibandingkan.

## 🎯 Tujuan

- Memahami dasar pembuatan antarmuka pengguna.
- Menampilkan data penilaian dalam bentuk visualisasi.
- Menghitung rata-rata kepuasan pengguna.
- Membandingkan nilai kepuasan antar kategori layanan.
- Menerapkan prinsip kemudahan penggunaan dalam desain dashboard.

## ✨ Fitur

- **Ringkasan statistik:** menampilkan jumlah penilaian dan rata-rata kepuasan.
- **Layanan terbaik:** menunjukkan kategori dengan rata-rata nilai tertinggi.
- **Grafik batang:** membandingkan nilai rata-rata setiap kategori layanan.
- **Filter kategori:** menampilkan data berdasarkan layanan yang dipilih.
- **Tabel penilaian:** menyajikan nama, kategori layanan, dan nilai pengguna.
- **Desain responsif:** menyesuaikan tampilan dengan ukuran layar perangkat.

## 🛠️ Teknologi yang Digunakan

- HTML untuk struktur halaman.
- CSS untuk desain dan tata letak.
- JavaScript untuk pengolahan data, perhitungan statistik, filter, dan visualisasi.
- Visual Studio Code sebagai editor kode.

Proyek ini tidak memerlukan API, database, maupun instalasi library tambahan.

## 🚀 Cara Menjalankan Proyek

1. Unduh atau clone repository ini ke komputer.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html`.
4. Jalankan file melalui browser dengan mengeklik dua kali file tersebut, atau gunakan ekstensi Live Server.
5. Pilih kategori layanan pada menu filter untuk melihat perubahan data, grafik, dan tabel.

## 📊 Data yang Digunakan

Proyek ini menggunakan data simulasi penilaian mahasiswa terhadap empat kategori layanan:

- Administrasi
- Fasilitas kampus
- Sistem informasi
- Layanan dosen

Penilaian menggunakan skala 1 sampai 5. Data hanya digunakan untuk pembelajaran dan bukan hasil survei nyata.

## 🧠 Implementasi Materi HCI dan Data Visualization

Proyek ini menerapkan beberapa konsep dari materi:

1. **Human-Computer Interaction (HCI):** antarmuka dirancang sederhana dan mudah dipahami.
2. **Data Visualization:** grafik batang digunakan untuk membandingkan rata-rata kepuasan.
3. **Usability:** informasi disusun secara konsisten dan filter dibuat mudah digunakan.
4. **User-centered design:** informasi ditampilkan untuk membantu pengguna memahami hasil penilaian layanan.
